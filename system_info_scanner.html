अनुमति (Permission), मदरबोर्ड स्लॉट्स एवं लोकल सर्विस स्कैन

सटीक लोकेशन, Mantra/Morpho बायोमेट्रिक सीरियल नंबर, मदरबोर्ड के RAM स्लॉट्स (DDR3/DDR4/DDR5), Max RAM क्षमता, बैटरी हेल्थ व SSD/HDD स्लॉट की जाँच करें:

सटीक लोकेशन (GPS + शहर)

GPS अनुमति से सटीक स्थान या नेटवर्क से शहर, पिनकोड व अक्षांश-देशांतर देखें।

लोकेशन जानने के लिए ऊपर "लोकेशन देखें" बटन दबाएं।
Morpho / Mantra सीरियल नंबर

कंप्यूटर में लगे Mantra MFS100/110 या Morpho L0/L1 की RD Service से असली सीरियल नंबर निकालें।

बायोमेट्रिक डिवाइस प्लग-इन करके "डिवाइस स्कैन" दबाएं।
कैमरा व माइक डिवाइस सूची

कंप्यूटर/मोबाइल से जुड़े वेबकैम, माइक्रोफ़ोन और स्पीकर के नाम देखें।

अभी तक अनुमति नहीं दी गई है।
अन्य USB डिवाइस पहचान

कनेक्टेड प्रिंटर, वेबकैम या अन्य USB हार्डवेयर का नाम व ID देखें।

कोई USB डिवाइस नहीं चुना गया है।
TPM 2.0 / हार्डवेयर सिक्योरिटी

ब्राउज़र से TPM / Windows Hello हार्डवेयर चिप की उपलब्धता नीचे दिखती है। सटीक वर्ज़न (TPM 2.0) हेतु tpm.msc चलाएं।

जाँच हो रही है...
Wi-Fi नाम व पासवर्ड CMD

ब्राउज़र सुरक्षा के कारण Wi-Fi पासवर्ड नहीं पढ़ते। Windows CMD में नीचे दिया गया कमांड चलाकर सभी सेव किए गए Wi-Fi पासवर्ड देखें:

netsh wlan show profiles name="*" key=clear | findstr "SSID Content"
पूर्ण कंप्यूटर व लैपटॉप हार्डवेयर अपग्रेड स्कैनर

मदरबोर्ड स्लॉट्स, DDR3/DDR4/DDR5, Max RAM, SSD/HDD, असली CPU नाम व बैटरी हेल्थ (%)

मदरबोर्ड व RAM स्लॉट्स

कुल स्लॉट्स (2 या 4), भरे/खाली स्लॉट और अधिकतम सपोर्टेड RAM (Max GB) बताएगा।

कौन-सा RAM व CPU?

असली CPU जेनरेशन नाम, RAM प्रकार (DDR3/DDR4/DDR5), DIMM/SODIMM व MHz बताएगा।

SSD (NVMe/SATA) व HDD

डिस्क प्रकार (NVMe M.2 / SATA SSD / HDD), कुल क्षमता (GB) और M.2 स्पोर्ट बताएगा।

बैटरी हेल्थ, BIOS व MAC

लैपटॉप बैटरी हेल्थ (%), BIOS डेट, सिस्टम अपटाइम, Secure Boot व MAC एड्रेस बताएगा।

चलाने का तरीका: "1-क्लिक .BAT टूल डाउनलोड" करके डबल-क्लिक करें, या "कमांड दिखाएं व कॉपी करें" दबाकर कीबोर्ड पर Win + R दबाएं, पेस्ट करें और Enter दबाएं। पूरी रिपोर्ट स्क्रीन पर दिखेगी, क्लिपबोर्ड पर कॉपी होगी और डेस्कटॉप पर PC_Details.txt में सेव हो जाएगी।
